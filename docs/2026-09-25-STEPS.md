### The research of 2026-09-25 (finding 3), recorded

- **GTK has no embeddable file chooser any more.** `GtkFileChooserWidget`, the only widget that could be
  put inside our own dialog, is **deprecated since GTK 4.10** (`Gtk-4.0.gir`: `deprecated="1"
  deprecated-version="4.10"`, "Direct use of `GtkFileChooserWidget` is deprecated"; the whole interface
  lives in `gtk/deprecated/gtkfilechooser.c`), and `gtk4-rs` marks its constructors
  `#[cfg_attr(feature = "v4_10", deprecated …)]`. This workspace builds with the `v4_12` feature and
  `clippy --workspace --all-targets -- -D warnings`, so using it fails the verification entry unless it is
  wrapped in `#[allow(deprecated)]` — a legacy path, which `AGENTS.md` forbids.
- **The folder is chosen by `GtkFileDialog::select_folder`** if we keep the platform's chooser: still a
  second dialog, but a *folder* dialog (no name, no extension), which is one question rather than two.
- **Or the folder browser is built**: `GtkDirectoryList` (a `GLib` model over a directory, not deprecated)
  + `GtkListView` + a hand-built path bar (`GtkPathBar` does not exist in GTK4), with its own keyboard,
  accessible names and tests — a component of its own, and the app's only directory browser. That is the
  part the human said to ask about before building.
- **"Remembered" has a second question**: the last export's folder lives in the window today
  (`export::Settings`), so it dies with the session. Remembering it across runs needs a file under
  `~/.config/pixlay/` — and ruling 8 of 2026-09-22 says "No configuration file".

same claim and must always agree; changing one is part of closing the step. A step becomes ✅ only when its
gate ruling is on disk — the five parts listed in `AGENTS.md` "Session and persistence discipline". A step
that is waiting on a human answer is ⏸, not 🚧.

A step whose "Human" line says **none** has no ruling to write: it closes with its **Result** subsection
(criteria → landing point → measured, plus the decisions it made), its status row, the "Current progress"
line, whatever shape it changed synchronized into `docs/CONTRACT.md`, and the commit.

## S19 · The count is 1..=9

**Goal**: ruling 34 — a single photo is a legal collage, and the window refuses nothing.

- **Work**: `MIN_SLOTS` / `MIN_PHOTOS` 2 → 1, `Selection`'s bounds and `layout_for` with them; the template
  generator and the committed library gain **one 1-slot layout** (a single cell covering the sheet) under

  one empty cell whose `+` asks for its photo; the GUI's callers (`Add photos…`, a drop, `+`) slice a

  refusing (`init --photo`, `edit --add-photo`: exit 1) and says so in `--help`; the frame is what gives a

- **Exit criteria**: a 1-slot document validates, renders, probes and exports through the CLI; the library's
  invariants still pass at every count 1..=9 (`templates --slots 1` lists exactly the new layout); a
  twelve-file drop lands nine photos and reports one message (`tests/` counts the toasts); `init --photo`
  with ten photos still exits 1 with its message; `edit --remove-cell` stops at one cell.
- **Not doing**: no partial-success command in core, no silent truncation anywhere, no 1-photo *special

- **Human**: whether a new document's frame starts at zero or at a small gap that reads as a border (the

## S20 · The gap is a gap

**Goal**: ruling 35 — the frame's number is the distance between two photos, and the same distance at the
sheet's border.

- **Work**: the visible region of a cell becomes `(sheet eroded by gapRel/2) ∩ (cell eroded by gapRel/2)`,
  so every seam measures exactly `gapRel` and the outer border too; `Frame`'s geometry, `Frame::covering`,
  `MAX_FRAME_REL` and the "a gap that empties a cell" check are recomputed against that reference; the
  rounded corner keeps applying to the eroded cell; the CLI's `--gap`, the dialog's per-cent rows and the
  `frame` field's shape are unchanged; `docs/CONTRACT.md` §1/§4 and the S11 measurement notes record that
  the same numeric value now means half the inset it did (only `gapRel = 0` renders byte-identically, and
  that is the promise the S11 ruling made).
- **Exit criteria**: a probe counts backdrop pixels across a seam — at `--long-edge 4000` and `--gap 4%`
  the run between two adjacent photos is **160 px ± 1**, and so is the run from the sheet's border to the
  outermost photo (the old meaning measured 320 px inside and 160 px at the border); the same probe passes
  for a rounded rectangle and for a single-slot document (which now shows one uniform border); the tests
  for a gap that empties a cell name the slot they always did.
- **Not doing**: no separate outer-margin field — one number is the whole frame.
- **Human**: none to decide; the look at both ends of the range is a walk item.

## S21 · The layout is a sketch

**Goal**: ruling 32 — the band's candidates are sketches of the geometry, and the band stops decoding.

- **Work**: `pixlay-render` gains the sketch renderer — each slot's outline stroked over the sheet's
  ground, the stroke width and the two colours as parameters with sane CLI defaults, drawn by the same
  `draw`-side geometry the document uses (no second geometry model); the CLI exposes it (`templates
  --sketch --out <png>`, or `render --template <name> --sketch` — the step picks one spelling and
  documents it); the GUI's band draws each candidate through that call, passing the **theme's** colours
  (a candidate is interface, not content); `candidate_templates()`'s per-candidate grid becomes one fixed
  thumbnail grid; the band's `request_gallery` loses the decode request and the shared preview-grade
  copies; `tests/layout.rs`'s "a candidate equals `pixlay-render render` of the same document" becomes
  "a candidate equals `pixlay-render … --sketch`" (RMSE 0, the same criterion re-aimed); the caption (the
  template's name, which is what `edit --template` takes) and the outline each cell already carries stay.
- **Exit criteria**: the band's sketch is pixel-identical to the CLI's at the same grid; the band's build
  requests **no** decode (the existing counter reads 0) and its cost is measured against S18's ruler, with
  the switch re-measured and recorded; the candidate set is still every layout with the document's cell
  count (ruling 25's filter stands); `docs/CONTRACT.md`'s S14 section is rewritten to the sketch (its
  seven live measurements about candidate renders and shared copies move to the archive's record with a
  note saying what replaced them).
- **Not doing**: no style in templates (there is nothing but geometry to draw), no sample photos, no
  user-authored sketches.
- **Human**: the sketch's legibility at the band's 128x96 (at the walk gate).

## S25 · The export's destination

**Goal**: findings 3 and 4 — the destination is always visible and always chosen in the export dialog, the
